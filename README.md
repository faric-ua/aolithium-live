# Aolithium Live

Свій Android-застосунок для батареї **Aolithium** (LiFePO4, плата JBD), щоб вона «жила далі»: виробник зник,
застосунок прибрали з Google Play. Показує все, що показував Aolithium 1.3, і більше — кожну комірку, різницю між ними,
усі температури, захисти людською мовою, лічильники захистів.

- **Лише читає** батарею — нічого в ній не змінює. Дані батареї нікуди не йдуть: інтернет застосунок використовує
  **лише** для оновлення з Google Диска автора («Оновлення застосунку» внизу головної).
- Android 8 і новіші, Bluetooth LE.
- Неофіційний: код свій, протокол — з відкритих джерел (`THIRD_PARTY.md`, `docs/PROTOCOL_JBD.md`).

Встановити: сторінка релізів → `Aolithium-Live-v…apk` (або Termux-меню, `docs/PHONE_SETUP.md`).
Інструкція (українською та англійською, зі схемами й знімками) — `docs/guide/guide.html`; у застосунку — значок **?** на головній.

Далі за планом (`docs/PLAN.md`): історія й графіки → сповіщення → батарея Logic Power (плата JK BMS) → обережні налаштування.
