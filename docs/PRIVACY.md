# Приватність

- Дані батареї нікуди не йдуть. Дозвіл `INTERNET` (з T37, v0.4.5) — **лише** для оновлення застосунку з Google Диска автора:
  телефон читає маленький файл версії й APK за відкритим посиланням, без входу в Google; телефон автора ще й пише
  свій встановлений APK у свої файли на Диску й перевіряє, що інші телефони їх бачать. Нічого про батареї, історію
  чи телефон при цьому не надсилається. `REQUEST_INSTALL_PACKAGES` — щоб відкрити вікно Android «Оновити» для
  перевіреного APK (розмір, SHA-256, той самий пакет, новіша версія, той самий ключ підпису).
- Оновлення можна вимкнути: «Перевіряти самому раз на день» → «Ні»; уся функція ховається одним перемикачем у коді
  (`core/UpdateFeature.kt`).
- «Мої батареї» (адреса Bluetooth, назва) — лише в пам'яті телефона; резервна копія Android вимкнена (`allowBackup="false"`).
- Android 8–11 вимагає дозвіл на місцезнаходження для пошуку Bluetooth — місцезнаходження застосунок не читає й не зберігає.
- Журнал зв'язку — лише в пам'яті, доки застосунок відкритий; переслати його можна тільки вручну («Поділитися»). Адреса там скорочена.
- Справжня адреса батареї faric у репо не пишеться (публічне репо; `scripts/audit_repo.py`).
