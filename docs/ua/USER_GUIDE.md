# Aolithium Live — інструкція

З версії 0.4.4 (T7, 20.10.2026) інструкція — **одна сторінка зі схемами й знімками екранів, українською та англійською**:

- джерело — `docs/guide/guide.html` (обидві мови поруч: `class="uk"` / `class="en"`);
- у застосунку — значок **?** на головній або «Ще» → «Інструкція» (`assets/guide/index.html`, збирає `scripts/build_guide.py`);
- картинки — знімки емулятора на демо-даних (`scripts/guide_images.py`), тест — `tests/test_guide.py`.

Раніше тут був текст старої «Довідки» (`ui/HelpScreen.kt`, той самий текст у трьох місцях). Він повністю перенесений
у нову інструкцію, разом зі списком «Що змінилось»; історія — у git і в `docs/PROJECT_LEDGER.md` (запис 0.4.4).
