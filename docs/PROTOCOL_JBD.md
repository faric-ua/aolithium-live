# Протокол плати JBD (як говорить Aolithium)

Зібрано 2026-10-16 з відкритих джерел (код Aolithium не розбирався):
- **aiobmsble** — `aiobmsble/bms/jbd_bms.py`, `docs/jbd_bms.md`, тести `tests/bms/test_jbd_bms.py` (Apache-2.0) — https://github.com/patman15/aiobmsble
- **esphome-jbd-bms** — `components/jbd_bms_ble/jbd_bms_ble.cpp` — https://github.com/syssi/esphome-jbd-bms
- **BMS_BLE-HA** (Home Assistant) — у списку батарей з платою JBD прямо названо «Aolithium batteries» — https://github.com/patman15/BMS_BLE-HA

## Чому це плата JBD (доведено 16.10)

1. Адреса Bluetooth батареї faric починається з `A4:C1:37` — саме за цим початком aiobmsble впізнає плати JBD.
2. BMS_BLE-HA прямо пише «Aolithium batteries» серед батарей з платою JBD.
3. Усі поля Aolithium 1.3 (Realtime, Parameters) збігаються з полями відповіді 0x03 і налаштувань JBD.

## Зв'язок

- **Лише Bluetooth LE.** Ні Wi-Fi, ні інтернету, ні хмари — тому Aolithium працює й без сайту виробника.
- Служба `FF00`; відповіді — сповіщення з `FF01`; команди — запис у `FF02`.
- Плата тримає **одне** підключення: поки Aolithium (чи цей застосунок) на зв'язку, інший телефон її навіть не бачить у пошуку.
- Сповіщення — по 20 байт; одна відповідь приходить 1–3 шматками (`JbdAssembler` збирає).

## Кадр

```
DD | A5 (запит) або код (відповідь) | код або стан | довжина | дані… | сума (2 байти) | 77
```

Сума = `0x10000 − (сума байтів від коду/стану до кінця даних)`, старший байт першим. Стан у відповіді: `00` — гаразд, `80` — помилка.

## Команди читання (лише їх надсилає застосунок)

| Команда | Байти | Що повертає |
|---|---|---|
| Основне | `DD A5 03 00 FF FD 77` | напруга, струм, ємність, цикли, дата, балансування, захисти, версія, %, ключі, комірки, температури |
| Комірки | `DD A5 04 00 FF FC 77` | напруга кожної комірки, мВ (по 2 байти) |
| Назва плати | `DD A5 05 00 FF FB 77` | текст (ASCII) |
| Лічильники захистів | `DD A5 AA 00 FF 56 77` | 11 лічильників по 2 байти (є не на всіх платах) |

Команди запису (`E0` залишок, `E1` ключі, `E2` балансування, `00/01` заводський режим, `FA` налаштування) застосунок
**не має** — `Jbd.readCommand` відмовляє на все, крім читання.

## Відповідь «Основне» (0x03) — номери байтів від початку даних

| Байти | Що | Як читати |
|---|---|---|
| 0–1 | напруга батареї | × 0,01 В |
| 2–3 | струм (зі знаком) | × 0,01 А; плюс — заряд, мінус — розряд |
| 4–5 | залишок ємності | × 0,01 А·год |
| 6–7 | повна (номінальна) ємність | × 0,01 А·год |
| 8–9 | цикли | шт. |
| 10–11 | дата виготовлення | рік = 2000 + (x >> 9), місяць = (x >> 5) & 15, день = x & 31 |
| 12–13 | балансування комірок 1–16 | біт на комірку |
| 14–15 | балансування комірок 17–32 | біт на комірку |
| 16–17 | захисти | 16 біт, див. нижче |
| 18 | версія програми | 0x80 → «8.0» |
| 19 | заряд | % |
| 20 | ключі | біт 0 — заряд дозволено, біт 1 — розряд дозволено; біт 7 — ємність/струм у 0,1 (батареї > 655 А·год, esphome) |
| 21 | кількість комірок | |
| 22 | кількість датчиків температури | |
| 23… | температури | по 2 байти: (x − 2731) / 10 °C |

Деякі плати (Chins) шлють після температур ще 7 байт — застосунок їх не читає (aiobmsble теж: там повтор інших полів).

### Захисти (біт = 1 — діє зараз)

| Біт | Що |
|---|---|
| 0 / 1 | перезаряд / переразряд комірки |
| 2 / 3 | перезаряд / переразряд батареї |
| 4 / 5 | гаряче / холодно для заряду |
| 6 / 7 | гаряче / холодно для розряду |
| 8 / 9 | завеликий струм заряду / розряду |
| 10 | коротке замикання |
| 11 | помилка мікросхеми плати |
| 12 | ключі вимкнено програмно |
| 13–15 | невідомі (показуємо номером) |

## Пароль

Деякі плати вимагають перед читанням `FF AA 15 <довжина> <пароль ASCII> <сума 1 байт>` (за замовчуванням «000000»).
Aolithium 1.3 пароля не питав — найімовірніше, не потрібен. Якщо плата мовчить на `03` — застосунок пише «Плата мовчить»
і радить надіслати журнал зв'язку; пароль додамо тоді (TODO).

## Що показує Aolithium 1.3 і чого ні (відео faric 16.10)

Показує: SOC, ключі (Charge/Discharge Switch «open» = дозволено), Balance State, Protection State («close» = усе гаразд),
напругу, струм, одну температуру, потужність, цикли, середню напругу, номінальну й залишкову ємність; вкладка Parameters —
межі напруг з налаштувань плати (читає з пам'яті плати в заводському режимі).
**Не показує:** кожну комірку, різницю між ними, усі датчики, які саме захисти, назву/версію плати, дату, лічильники захистів.

## Перевірено тестами (`JbdTest.kt`)

Справжні кадри з тестів aiobmsble (15,6 В · −2,87 А · 100 % · 4 комірки 3,430/3,425/3,432/3,417 В · 3 датчики), кадр
довшої відповіді Chins, кадр шматками по 20 байт, сміття перед кадром, зіпсована сума, зіпсований кінець, загублений
шматок, два кадри в одному сповіщенні, біт «великої батареї», біти захистів. Демо-кадри дають рівно числа з відео
Aolithium (13,31 В · 93 % · 86,31 з 92,34 А·год · 123 цикли · 12,3 °C).
