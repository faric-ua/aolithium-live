  («автоматично»). Змінити вибір: Android 12+ — затисни віджет → налаштування (`widgetFeatures="reconfigurable"`),
  старші — прибрати й додати знову. Вікно відкрите для домашнього екрана (`exported`) — тому приймає лише номер
  **нашого** віджета (`Widgets.ownProvider`), чужий — закривається нічого не зробивши. Прибрали віджет — вибір забуто

     «батарея далеко — підійди ближче», і те саме в повідомленні про невдале підключення.

  4. остання спроба — `autoConnect` (Android сам підключиться, щойно побачить батарею; до 30 с).
  Журнал зв'язку тепер пише, коли саме обірвалось: «ще до з'єднання» / «під час читання» / «після даних».
