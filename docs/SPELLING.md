# Правопис і терміни (T38)

Українські тексти застосунку, інструкції, меню Termux і документів — сучасною українською (правопис 2019),
простими словами, на «ти». Англійська пара й словник англійських слів — `docs/LANG_EN.md`.
Перед новим текстом — глянути сюди; спірне — спитати faric.

## Терміни проєкту

| Правильно | Не так | Примітка |
|---|---|---|
| перерозряд (перерозряду, перерозрядом) | переразряд | «розряд» → «перерозряд», як «перезаряд» |

| комірка, комірки | банка, елемент | |
| балансування (процес), балансир (пристрій JK) | балансировка | мітка на плитці — «вирівнюється» (просте слово, те саме значення) |
| ключі плати (MOS) | мосфети, транзистори (у тексті для людини) | «ключ заряду / розряду» |

| зарядний (пристрій) | зарядник | |

## Граматика, що вже траплялась

- Порівняння з неживим: **вища / нижча / швидша за інші** (знахідний), не «за інших».
- **із** перед з-, с-: «рахую **із** залишку», «командою **із** застосунку».
- Назву в лапках відмінюємо, коли перед нею прикметник: «з увімкненим **«Записом у фоні»»**.
- Вати / ампери / вольти після числа — лічильна форма як є: «50 А», «кілька десятків ват».
- Відсоток для екранного читача — знаком: «Заряд 93 %» (читається з правильним закінченням), не «93 відсотків».
- Форми «підключаюсь», «не вдалось», «нема» — допустимі розмовні, лишаємо.
- Ключі лічильників захистів (`JbdParser.ERROR_COUNT_NAMES`) — водночас і текст для екрана: правити разом
  з `Glossary.forCounter`; старі збережені назви `LastSnapshot` бере за номером.

## Спірне — чекає слова faric

- «шторка» ↔ «панель сповіщень» (так у Samsung).
- «прочерки» ↔ «риски».
- «Заряд: дозволено / вимкнено» ↔ «увімкнено / вимкнено» ↔ «дозволено / заборонено» (пара слів не протилежна).
- «за замовчуванням» ↔ «типово» / «спершу» (`guide.html` 747, `LANG_EN.md`, протоколи).
- «Версія заліза», «залізо» (журнал зв'язку) ↔ «апаратна версія».
- «Зарядний» (як іменник) ↔ «Зарядний пристрій».
- «скрін» ↔ «знімок екрана».
- «торкни» ↔ «торкнись» (обидва правильні; зараз здебільшого «торкнись»).
- «скільки ват / ампер / вольт» ↔ «ватів / амперів / вольтів» (обидві форми трапляються в словниках).

## Рішення faric (20.10.2026, спірне з T38)

- «шторка» (не «панель сповіщень»).
- Ключі плати: «дозволено / заборонено» (не «дозволено / вимкнено»).
- Картка й рядок про зарядний: «Зарядний пристрій» (не просто «Зарядний»).
- Звертання в підказках: «торкнись» (не «торкни»).
- Решту спірного (прочерки, «за замовчуванням», «скрін», «ват / ватів») лишаємо як є: обидва варіанти припустимі.
- Загальне правило faric: у чаті з ним — як зручно, а **в застосунку, інструкції й сповіщеннях — лише літературна українська**.
