# Інтерфейс Aolithium Live — контракт

Основа — стиль **Track Catcher** (ведучий за стилем у застосунках faric): темний фон, картки з рамкою, зелена рамка «вибрано»
без галочок, значки лініями, власні вікна замість сірих діалогів Android. Код: `ui/Palette.kt` (усі кольори), `ui/Ui.kt`
(кнопки, картки, пігулки стану). Автоперевірка: `python3 scripts/audit_ui.py` (UI-01…UI-10, ті самі, що в Track Catcher).

| Роль | Колір |
|---|---|
| Фон / картка / рамка | `#0E1116` / `#171C23` / `#333D4B` (як Track Catcher) |
| Текст / другорядний | `#F2F5F8` / `#A3AEBB` |
| **Акцент** (головна дія, дуга заряду, найвища комірка) | `#5EC8F2` — свій, блакитний «електричний» (Track Catcher — бурштин) |
| Гаразд / дозволено / балансується | `#62D296` |
| Увага (найнижча комірка, мало заряду, холод/спека) | `#F0B968` |
| Біда (захист спрацював, ключ вимкнено, помилка зв'язку) | `#FF7A88` |

**Кнопки — на всю ширину** (faric 18.10 23:49): `Ui.grid` — по дві в рядку рівної ширини, непарна остання — на весь рядок; у вікнах так само («Закрити/Скасувати» — остання, праворуч). Довгі підписи (демо) — по одній на рядок.

Стан — завжди **словом і кольором** (пігулка «Заряд: дозволено»), не лише кольором.

**Екран не повертається — лише книжкова** (faric 19.10.2026 04:25: «потрібно заборонити переворот екрану»):
`android:screenOrientation="portrait"` у маніфесті, аудит UI-06. До v0.2.5 правило було навпаки («орієнтацію не блокуємо»,
з Track Catcher). Альбомний варіант (`twoPane`) у коді лишається: на планшетах і складаних (≥ 600 dp) Android 16
заборону повороту ігнорує, і там він знадобиться. Відкрите вікно й далі переживає перестворення екрана (шрифт, тема).

| Екран | Книжкова | Альбомна (≥ 600 dp, лише планшети) |
|---|---|---|
| Батареї (головна) | доступи → мої батареї → пошук | ліворуч мої батареї, праворуч пошук |
| Батарея | вкладки внизу: Зараз · Комірки · Графіки · Плата · Ще; картки однією колонкою | ті самі вкладки; картки у дві колонки |
| Довідка | картки по черзі | дві колонки карток |
